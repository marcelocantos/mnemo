# Vendored zstd

Upstream: https://github.com/facebook/zstd
Version:  v1.5.7
Files:    zstd.c is the upstream single-file amalgamation, generated by
          `build/single_file_libs/create_single_file_library.sh` from the
          release tarball; zstd.h is lib/zstd.h verbatim.

The amalgamation is used rather than the ~40-file lib/ tree because cgo
only compiles C sources in the package directory itself, and zstd's
sources use relative includes across common/ and compress/. It defines
ZSTD_MULTITHREAD internally, so ZSTD_c_nbWorkers works without extra
build flags — which is the whole reason for binding to C at all.

Licensed BSD-3-Clause (LICENSE.zstd). zstd is dual-licensed BSD-3-Clause
OR GPLv2; we take the BSD option, which is compatible with mnemo's
Apache-2.0. The GPLv2 alternative is deliberately NOT exercised and its
COPYING file is deliberately not vendored.

## Updating

    curl -sL -o zstd.tar.gz https://github.com/facebook/zstd/releases/download/vX.Y.Z/zstd-X.Y.Z.tar.gz
    tar xzf zstd.tar.gz && cd zstd-X.Y.Z/build/single_file_libs && sh create_single_file_library.sh
    cp zstd.c <repo>/internal/zstdc/zstd.c
    cp ../../lib/zstd.h <repo>/internal/zstdc/zstd.h
    cp ../../LICENSE <repo>/internal/zstdc/LICENSE.zstd

Then update the version above and run the package tests.
