## Product faults

- `37b3a14` fixes detection of newer same-size source files within a second. The variable-width RFC3339 timestamp comparison missed a change from whole seconds to fractional seconds and falsely flagged the reverse. `TestSameSecondRewriteIsReportedChronologically` failed both cases on the original code and passed after comparing parsed timestamps.
- `b8c2f5b` fixes a restarted Claude watch read that overwrote a later bulk cursor and indexed an anonymous line twice. A synthetic interleaving moved the stored offset from 381 to 247 and produced two copies. The regression passed after restricting the absolute reset to the first commit and respecting progress made by another writer. I03 also failed the new test because its change to the final cursor left the earlier periodic write and duplicate insert exposed.
- `e2b7274` recovers Cursor WAL updates that produce no filesystem event. The previous safety poll looked for JSONL growth. The new poll tests Cursor fingerprints within the existing path budget and refreshes changed stores. The regression uses a WAL-only transaction and calls the real poll without an event.

The three fault tests drive production Store methods with real temporary SQLite databases. The tests control timestamps, transaction order and event delivery directly to make these cases deterministic. The isolated daemon journey covers ingestion through MCP as a separate check.

## Method

- Ran original tests with `go test -tags=sqlite_fts5 -count=1` and the selected group per mutation. Each group had a clean control. Original-suite runs used the `5802d98` version of product code where fixes had already been applied. New tests were selected separately for clean and mutant runs.
- Used Go's `-overlay` to replace one source fragment at a time. The report retains substitutions and named failing tests. Test inputs were generated in a private home and temporary directories. Pueue job `1025` recorded the first batch and job `1064` resumed its saved measurements and completed the sweep. The default group started at two slots and was changed externally during the audit. The jobs ran sequentially and Go compilation and runtime parallelism stayed capped at two.
- Counted an executed, observable test failure as a catch. Build errors, transient test runner failures and edit mistakes are outside the denominator. Equivalence reasoning applies to supported product inputs and the behaviour named in the corresponding row.
- Five preliminary runs selected the Cursor JSONL group for Cursor SQLite mutations. Those results were discarded and the variants were rerun with the SQLite group.
